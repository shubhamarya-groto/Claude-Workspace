Scope of Work

Phase 1 - Product & UX Audit
- Audit the current website + platform experience across both company and job seeker flows.
- Identify UX friction, onboarding issues, dashboard optimization opportunities, mobile usability gaps, & blockers.
- Review competitors you mentioned to identify opportunities and positioning gaps.

Phase 2 - UX Strategy & Information Architecture
- Map ideal user journeys and happy paths (Aha moments!)
- Simplify flows and reduce friction for non-technical users
- Define engagement loops, and dashboard structure before redesigning screens.

Phase 3 - UI/UX Revamp
- Redesign the platform with a cleaner, more intuitive, and mobile-first experience.
- Improve tables, cards, posting flows, profile layouts, navigation, and overall usability.
- Share concepts/mockups collaboratively before finalising directions.

Main UX Goals

*  Reduce clicks 
*  Simplify onboarding 
*  Improve mobile UX 
*  Increase engagement 
*  Improve dashboard usability 
*  Make profiles feel more valuable 
*  Create cleaner, more intuitive flows
